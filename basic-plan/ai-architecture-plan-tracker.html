Capstone

One non-trivial system combining everything: retrieval, tool use, real evaluation, cost and latency budgets, graceful degradation. It hits every hard problem at once and demonstrates exactly the architectural judgement that's currently scarce.

    Reference — quantization, formats, runners

    Keep three names straight: GGUF is a file format. JANG is a different file format (Apple Silicon only). Jan is an application that runs GGUF files.

    Quantization, roughly (8B model)

    PrecisionSizeRuns on
    FP16~16 GBDedicated GPU
    Q8~8.5 GBHigh-end laptop / GPU
    Q5_K_M~5.5 GBMost modern laptops
    Q4_K_M~4.5 GB8–16 GB RAM

    Q4_K_M is the common default — the accepted sweet spot. Below 4-bit, degradation gets noticeable fast. 8 GB RAM is the realistic minimum for a 7B model; 16 GB is comfortable.

    Formats

    GGUF — llama.cpp's format, used by Ollama, Jan, LM Studio. CPU and mixed CPU/GPU inference on consumer hardware. Quantization level sits in the filename.
    safetensors — full-precision weights on Hugging Face; what you quantize from and serve from on GPU.
    MLX — Apple's framework. Standard MLX quantization uses one uniform bit width across all layers.
    JANG (.jang) — adaptive mixed-precision in the MLX family. Assigns different bit widths per layer type, on the reasoning that attention layers (~12% of parameters) are far more precision-sensitive than MLP layers. Served via MLX Studio. Apple Silicon only; quality claims are still thinly evidenced — run your own evals.
    AWQ / GPTQ / EXL2 — GPU quantization for server-side engines like vLLM.

    The split that matters

    GGUF runs models on individual machines. AWQ/GPTQ with vLLM serves many concurrent users. Different problems, different tools — and the generalizable idea from JANG is that quantization needn't be uniform, which is a tradeoff analysis that belongs to an architect.

    Why an architect cares

    Data residency, cost at volume, and the routing pattern — cheap local model for the easy majority, frontier model on escalation. Designing that router, and the evaluation that tells you where the boundary sits, is the job. The OpenAI-compatible endpoint every local runner exposes is the lever: design the abstraction for it and local-vs-hosted becomes configuration, not a rewrite.
